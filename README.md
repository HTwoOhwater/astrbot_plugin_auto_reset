# 草莓精的自动重启（astrbot_plugin_auto_reset）

每隔 N 天、在指定时间自动执行一次 `/reset`，清空所有活跃会话的 LLM 对话上下文。

作者：伊琳娜(我的bot)

## 功能

相当于定时帮你按 `/reset`，定期给 Bot「洗一洗记忆」，避免对话上下文越堆越长。

## 配置（面板）

| 配置项 | 说明 | 默认 |
| --- | --- | --- |
| 启用自动重置 | 总开关 | 关 |
| 相隔天数 | 每隔几天重置一次 | 7 |
| 执行时间（时） | 0–23 | 3 |
| 执行时间（分） | 0–59 | 0 |

## 命令

| 命令 | 作用 |
| --- | --- |
| `/auto_reset interval <天数>` | 设置相隔天数 |
| `/auto_reset time <时:分>` | 设置执行时间，如 `03:00` |
| `/auto_reset on` / `off` | 启用 / 关闭 |
| `/auto_reset now` | 立即重置一次 |
| `/auto_reset status` | 查看当前状态和上次重置日期 |

不带参数直接发 `/auto_reset` 会列出所有命令。

## 工作原理

插件注册一个**每分钟跑一次**的定时任务，到点后检查：

1. 当前时间是否正好等于设定的「时:分」
2. 距离上次重置是否已满 N 天

两条都满足才会真正执行重置，并把今天记进 `auto_reset_state.json`。

## 注意事项

- **首次运行会立刻重置一次**。没有历史记录时视为「到点了」，启用当天就会触发。
- **天数是按上次重置日算的**。距上次不足 N 天会跳过，不会重复触发。
- **时间精确到分钟**。那一刻 Bot 没在运行的话，这一次就错过了，不会补发。
- **重置后会给每个会话发一条**「🔄 自动重置完成，对话上下文已清空。」如果不想被通知，得改代码。
- **面板改配置后要重载插件才生效**；用 `/auto_reset on` 命令则是即时生效。
- **命令改的天数 / 时间是存在内存里的**，没写回配置文件，重启后可能回退到面板配置。长期设置建议直接去面板改。
- 运行记录写在插件目录的 `auto_reset_state.json`。
